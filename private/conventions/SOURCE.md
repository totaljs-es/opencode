# Source

`check.js` is a copy of `tools/check.js` of https://github.com/totaljs-es/conventions (MIT), taken at: 77a687a README: document the Claude Code plugin and how to install it.

Totem runs it on the files that its tools write in a Total.js 5 project (a project whose `package.json` depends on `total5`) and gives the findings to the model with the tool result. To update it, copy the file again from that repository.
